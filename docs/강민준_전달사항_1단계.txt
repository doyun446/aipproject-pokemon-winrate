[1] 엔진
- npm 버전(0.11.11)은 레귤레이션 M-C 포맷이 없고, 메가 루카리오Z·메가 한카리아스Z 등 4개 메가 특성이 틀려 있어
- 그래서 GitHub 최신 버전을 커밋 5b88c47로 고정해서 sim/engine에 빌드했어 (설치 방법은 README)
- 포맷: gen9championsbssregmc, 데이터는 Dex.forFormat(포맷)으로 불러야 챔피언스 규칙이 적용돼
- 능력 포인트는 변환 필요 없음! 세트의 sp 값을 그대로 evs 칸에 넣으면 챔피언스 규칙대로 계산돼 (2단계 '변환 만들기'는 빼고 실수치 대조만 하면 돼)

[2] 세트 데이터: data/sets60_v2.json (엑셀 검토용은 sets60_v2.csv, 한국어판 sets60_v2_ko.csv)
- Smogon 2026년 9월 M-C 1500 구간 기준 사용률 상위 60종, 세트 205개
- 세트 = 형태 × 도구 종류(메가/구애/기합의띠/공격 강화/내구/필드·역할), 같은 도구 안에서 기술 구성이 다른 변형도 있음
- 종 안 비중 10% 이상 세트만 포함, 나머지는 포함된 세트 비율대로 정규화
- 검산: 세트 비율로 다시 계산한 기술 채용률이 실제와 평균 7.7%p 차이 / 205개 전부 최신 엔진 규칙 검사 통과

주요 필드
- set_id, form(형태 이름), ability, item, nature, sp(H/A/B/C/D/S), moves(4개)
- ratio: 그 종 안에서 이 세트를 뽑을 비율 (판마다 양쪽 다 이 비율로 뽑으면 됨)
- roles, support_type: 역할 태그와 서포트형 표시 (5단계 보정용)
- eval_sp: 평가 전용 배분 (학습 데이터에는 절대 넣으면 안 됨)
- *_ko: 한국어 이름 (데모용), 이름 사전은 data/names_ko.json

[3] 엔진에 세트 넣을 때 주의
- 메가 세트는 species를 원래 포켓몬으로 넣고(예: Salamence + Salamencite), 특성도 원래 포켓몬 특성으로 넣어야 규칙 검사를 통과해. 메가진화는 배틀 안에서 해야 함 → 1:1 정책에 첫 턴 메가진화 넣어줘
- 메가 플라엣테는 원래 형태가 Floette-Eternal
- 로토무 폼(Rotom-Wash, Rotom-Heat)은 폼 이름 그대로
- 메타몽은 포함하기로 했어. 변신해도 HP는 자기 거(48)라 거울전이 아님. 피처는 변신 후 능력치(상대 능력치 + 자기 HP + 구애스카프)로 계산해야 하고, 구애라 변신 후 첫 기술에 고정됨

[4] 능력 포인트 흔들기 (초안, 확인 부탁)
- sim/jitter.js의 makeRng(기본시드, 판번호, 쪽), jitterSP(set.sp, rng) 쓰면 돼
- 30%는 그대로, 70%는 1~4점 옮김 (합계·최대 32 유지)
- node sim/test_jitter.js로 검사 가능 (41만 번 돌려서 규칙 위반 0, 평가 배분 겹침 0)
- 결과 파일에 set_id, 실제로 쓴 sp, 흔들기 여부, 평가 배분 여부, 시드 같이 저장해줘

[5] 같이 정해야 할 것
- 1천 판 속도 재고 40종(대면 870→1,560개, 대면 커버율 54%) vs 60종(3,540개, 71%) 결정
- 대면당 판 수: 40종이면 12판(총 약 5만 6천 판) 제안
- 서포트형 보정 때문에 1:1 상태 주입에 날씨 말고도 벽(남은 턴), 설치기, 필드, 트릭룸 넣을 수 있는지
- 흔들기 양(최대 4점, 30% 유지)이 괜찮은지

자세한 건 진행 보고서에 다 정리해 뒀어. 보고서 링크 따로 보낼게!

[6] 처음 보는 포켓몬 처리 (4단계 모델 설계 때 같이 봐줘)
- 실제 대전 상대의 약 29%는 우리 60종 밖이야. 지금 계획(포켓몬 임베딩 + MLP)으로는 임베딩이 없는 포켓몬을 판단 못 해
- 제안 1: 학습할 때 10~20% 확률로 포켓몬 임베딩을 "모르는 포켓몬" 칸으로 바꿔서 학습 → 처음 보는 포켓몬은 그 칸 + 피처(실제 능력치, 타입, 스피드 비교, 최대 데미지 비율, 몇 방에 쓰러지는지)로 예측. 피처는 어떤 포켓몬이든 엔진 데이터로 계산 가능
- 제안 2: 4단계 평가에 "처음 보는 포켓몬" 평가 추가. 60종 중 5종 정도를 학습에서 완전히 빼고 그 5종 대면을 얼마나 맞히는지 재기 (지금 계획한 "처음 보는 대면", "처음 보는 배분"에 하나 더)
- 제안 3: 데모에서 60종 밖 포켓몬이 들어간 대면은 자동으로 "신뢰도 낮음" 표시
- 데이터 쪽: 60종 밖 239개 형태의 기본 세트를 data/default_sets.json 에 만들어 뒀어 (Smogon 1위 특성·도구·배분 + 채용률 상위 기술, 최신 엔진 규칙 검사 전부 통과). 학습에는 넣지 말고, 데모에서 처음 보는 포켓몬의 피처 계산용이나 처음 보는 포켓몬 추가 평가용으로만 써줘. 60종 세트와 합치면 실제 사용의 약 98%에 세트가 있어
